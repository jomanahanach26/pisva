# PISVA

**Together, nothing gets lost.**

PISVA is a family coordination app designed to help families stay organized while supporting parents and relatives with appointments, administrative matters, and everyday follow-ups.

## The Problem

When several family members share responsibilities, important information can get lost between phone calls, messages, and individual notes.

It becomes difficult to know:
- What has already been done?
- What still needs attention?
- Who is responsible for the next step?

## Our Solution

PISVA brings family follow-ups into one shared space.

### Planned Features

- **Radar:** A dashboard showing what needs attention.
- **Cases:** Track administrative matters and their next steps.
- **Responsibility Handoffs:** Transfer ownership only when the recipient accepts.
- **Appointments:** Organize appointments and request accompaniment.
- **Family Notes:** Leave notes linked to a case or appointment.
- **History & Archive:** Keep a record of completed actions and outcomes.

## Project Status

**Phase: UX design and validation**

The application is currently in the planning and prototyping stage. Development has not started yet.

## Planned Technology Stack

- Frontend: React and TypeScript
- Backend: Python and FastAPI
- Database: PostgreSQL
- Containers: Docker
- CI/CD: GitHub Actions
- Infrastructure: Terraform and Azure (to be evaluated)

## Project Goal

Build a useful, privacy-conscious family coordination product while demonstrating end-to-end software development and DevOps practices.
